# stm32f446re_game_lib

A lightweight game/graphics library for STM32F446RE and ST7789 displays written in bare-metal C.

## Features

- [x] SPI ST7789 driver
- [x] Pixel drawing
- [x] Horizontal lines
- [x] Vertical lines
- [x] Bresenham line drawing
- [x] Rectangle drawing
- [x] Filled rectangles
- [x] Midpoint circle drawing
- [x] Filled circles

## Planned Features

- [ ] Bitmap fonts
- [ ] Triangle drawing
- [ ] Filled triangles
- [ ] Sprite rendering
- [ ] Snake game demo
- [ ] SPI DMA support

## Target Hardware

- STM32F446RE
- ST7789 TFT Display
- Bare-metal C (no HAL)

Work in progress.
